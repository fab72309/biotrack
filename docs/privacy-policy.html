BioTrack - Politique de confidentialite

Version MVP - a adapter avant soumission App Store.

BioTrack est une application de suivi personnel. Par defaut, les donnees de l'utilisateur sont stockees localement sur l'appareil. L'application ne cree pas de compte utilisateur et n'envoie pas les donnees a un serveur BioTrack.

Donnees stockees dans l'application

  • Protocoles, supplements, rappels et metriques saisis dans l'application
  • Entrees de suivi (check-ins, valeurs de metriques, historiques)
  • Preferences locales (ex. options d'affichage, configuration de sync)

HealthKit / app Sante

Si vous activez l'integration Sante (HealthKit), BioTrack demandera uniquement les permissions necessaires aux categories que vous choisissez d'autoriser (par exemple sommeil, pas, poids, frequence cardiaque au repos, HRV).

Les donnees HealthKit sont utilisees pour pre-remplir des metriques dans BioTrack. Elles restent sur votre appareil, sauf si vous exportez volontairement vos donnees via les fonctions d'export de l'application.

Vous pouvez retirer l'acces a Sante a tout moment depuis les reglages iOS.

Notifications

Les rappels sont planifies localement sur votre appareil via le systeme de notifications iOS, apres votre consentement.

Export / sauvegarde

L'application permet l'export manuel des donnees (y compris une option d'export chiffre). Les fichiers exportes sont stockes a l'emplacement que vous choisissez et restent sous votre controle.

Partage avec des tiers

BioTrack ne vend pas vos donnees et n'utilise pas de tracking publicitaire. Si vous partagez un export, ce partage est initie manuellement par vous via iOS.

Contact

Pour toute question relative a la confidentialite ou au support, utilisez la page Support.

Avant publication App Store: completez les informations de contact (email/site), la date de mise a jour et harmonisez ce texte avec les declarations "App Privacy" dans App Store Connect.
